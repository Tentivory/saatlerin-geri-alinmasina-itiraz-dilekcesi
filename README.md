# T.C. RESMİ SAAT MÜDÜRLÜĞÜ
## Geri Alınan Saatin İdari İtiraz Dilekçesi Üreticisi

> **UYARI:** Bu yazılım bilimsel bir şakadır değildir. Saat bir varlıktır. Saat davacıdır. Saat, bir saat geri alınmayı kişilik hakkı ihlali sayar.

Her sonbaharda bir saat çalınır. Kimse soru sormaz. Bu depo o soruyu resmi evrak formatında sorar.

## Ne Yapar?

`dilekce.py` çalıştığında:

1. Kaybolan saatin kimlik numarasını üretir (uydurma, ama resmi görünür).
2. T.C. Resmi Saat Müdürlüğü'ne hitaben bir itiraz dilekçesi basar.
3. Zarar kalemini hesaplar: kaybedilen kahvaltı, kaçırılan otobüs, yarım kalan rüya.
4. İade talebini 60 dakikalık kesin hüküm olarak kaydeder.

## Kuruluş

```bash
python3 dilekce.py
python3 dilekce.py --davaci "Pazar Uykusu"
```

Bağımlılık yoktur. Sadece Python 3 ve biraz kırgınlık yeter.

Hayır. Faiz işlemez. Sadece kırgınlık işler.

**Yaz saati ileri alınınca saat zengin mi olur?**  
Hayır. O saat de zaten milletin malıdır; idare sadece kiralık görünür.

**Patates var mı?**  
Yok. Kesinlikle yok.
